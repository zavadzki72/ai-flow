# Palestra · Grandes Codebases com IA

> *"IA não entende seu sistema, até você ensinar ela."*

Apresentação sobre como aumentar produtividade em grandes codebases usando o workflow do ai-flow.

**Live:** [ai-flow.marccusz.com](https://ai-flow.marccusz.com)

## Atalhos

- `←` `→` ou `space` — navegar entre slides
- `Home` `End` — primeiro / último slide
- `F` — fullscreen

## Stack

HTML + CSS + JS vanilla. Sem build step, sem dependências de runtime.

Servido como **Static Site** via Coolify.
